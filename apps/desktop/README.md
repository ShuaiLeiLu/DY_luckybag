# 桌面管理界面

桌面端管理账号、任务池、执行日志与历史；抖音业务由 Node.js 安卓协议客户端直接执行。

当前真实验收阻塞：手机确认后服务端仍返回 1049，未保存账号会话。下列流程已通过本地夹具联调，但不能视为真实登录已可用。40.7.0 版本参数和 CSRF 已补齐，真实签名与设备证明尚待适配。

1. 点击“添加账号”，用抖音 App 扫码并确认，自动保存会话和协议设备参数。
2. 账号卡片点击“验证协议”，输入当前有效福袋的内部 room_id。
3. 报告分别显示登录态、签名接受情况与福袋详情。两项真实读取均确认后才允许启动。
4. 账号过期时使用“重新扫码登录”，重新验证后恢复。

账号凭据只保存在主进程，使用系统 safeStorage 加密；渲染层仅收到账号摘要和脱敏验证报告。
扫码流程使用 `/passport/mobile/get_qrcode/` 与 `/passport/mobile/check_qrconnect/`，采用安装包中大屏扫码分支的 `source=pad` 参数。
这只是 HTTP 协议参数，不启动 Android 系统。设备 ID 由注册接口分配，Cookie 与令牌只接受服务端返回值。
登录窗口关闭、二维码过期或未知状态都会停止。旧网页登录态不会自动当成安卓会话使用。
没有模拟器、外部浏览器执行窗口、手机 HTTP 桥接或 WebView 登录入口。

需要评论、粉丝团、关注、观看、付费等未验收条件的目标会跳过。
红包领取与随机互动停用；当前仅实现明确无额外动作条件的协议参与。
无明确证据的开奖结果记录“未知”，不计入未中奖样本。

开发：npm run desktop:electron:dev；构建：npm run desktop:electron:build:win。
