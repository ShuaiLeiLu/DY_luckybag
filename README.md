# 抖音福袋助手

基于 Electron + Vue 3 的抖音直播间福袋自动参与工具。

> **⚠️ 重要说明**  
> 这是初始版本，功能尚不完善，效果不明显。  
> 本项目仅作为个人娱乐和学习用途，不建议用于实际使用。

## 功能特性

- 自动扫描抖音直播间福袋（支持全部搜索和分类搜索）
- 智能预测中奖概率（基于参与人数、剩余时间、在线人数等因素）
- 自动选择最优福袋并参与
- 支持多账号管理，账号间完全隔离
- 丰富的配置选项（概率筛选、参与次数、运行时长等）
- 实时统计参与次数、中奖次数、钻石数量

## 使用说明

### 添加账号

1. 点击"添加账号"按钮
2. 在弹出的浏览器窗口中扫码登录抖音
3. 登录成功后自动保存 Token 和用户信息

### 配置参数

- **概率筛选**：只参与预测概率 ≥ 设定值的福袋（默认 10%）
- **二次检查**：参与前再次检查概率（默认 5%）
- **参与次数**：单账号最大参与次数（默认 80 次）
- **运行时长**：单账号最长运行时间（默认 3 小时）
- **停留时长**：参与后在直播间停留时间（默认 5 秒）
- **过滤人数**：只参与在线人数 ≤ 设定值的直播间
- **启用红包**：是否参与红包
- **随机互动**：参与时随机点赞、评论等

### 启动运行

1. 点击账号的"启动"按钮
2. 系统自动打开浏览器并加载 Token
3. 开始扫描福袋并自动参与
4. 日志区域实时显示运行状态

### 账号管理

- **刷新**：手动刷新账号信息
- **暂停/继续**：控制账号运行状态
- **删除**：删除账号及本地 Token

### 核心逻辑

#### 福袋扫描

采用两种方式扫描：
1. 搜索全部直播间（`/webcast/feed/`）
2. 按分类搜索（`/webcast/web/partition/detail/room/v2/`）

扫描后会剔除过期福袋、计算预测概率、按开奖时间排序。

#### 参与流程

```
扫描一轮 → 选择最优 → 参与 → 等待开奖 → 清空福袋池 → 重新扫描
```

每次参与完一个福袋后，清空整个福袋池并重新扫描，确保信息最新。

#### 概率预测

考虑因素：
- 当前参与人数
- 福袋剩余时间
- 直播间在线人数
- 福袋总时长
- 时间衰减因子

#### 账号隔离

每个账号使用独立的 Session Partition（`persist:douyin_{accountId}`），Cookie 和缓存完全隔离。

#### 签名算法

完整实现抖音签名算法：
- RC4 加密
- SM3 哈希
- a_bogus 生成
- X-Bogus 签名



## 常见问题

**Q: 登录失败或 Token 无效？**  
A: 检查网络连接，尝试刷新账号信息或重新添加账号。

**Q: 扫描不到福袋？**  
A: 检查概率筛选是否过高，尝试手动扫描，查看日志错误信息。

**Q: 无法参与福袋？**  
A: 确认账号已登录，福袋条件符合（需包含"发口令"和"手动参与"）。

**Q: 浏览器窗口无法打开？**  
A: 检查 Electron 安装，尝试重启应用，查看控制台错误。
